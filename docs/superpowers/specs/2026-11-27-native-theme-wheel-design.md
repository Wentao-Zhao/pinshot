# PinShot A 版界面与置顶图片滚轮缩放

用户已选择 A「原生简洁」方案，并要求置顶图片支持滚轮放大缩小。

- 浮动工具栏保持单排：绘图工具、颜色、撤销/重置、置顶/OCR、取消/复制/完成；分组用细分隔线。
- macOS 浅色与深色使用相同布局，系统语义色提供文字与控件对比度。所有弹窗继承系统外观，不强制深色。系统外观变化时更新 CALayer 的已解析颜色。
- 工具选中态使用蓝色，鼠标悬停使用轻微背景色，菜单栏使用透明底四角取景框模板图标。
- 设置窗口采用原生表单分组；OCR 和置顶工具条共用表面、边框和前景色。
- 图片和标注内容不随外观变色。
- 滚轮向上放大、向下缩小，触控板连续滚动平滑缩放；忽略横向和惯性事件，避免松手后继续缩放。
- 鼠标下的图片位置作为缩放锚点，保持图片比例；遵循现有最小窗口尺寸，最大适配当前显示器可用区域。角落拖拽、复制原图和 OCR 行为继续工作。
- 仍兼容 macOS 13。交付本地构建产物，不自动发布 GitHub release。

验证：真实 AppKit 交互测试覆盖滚轮路由、几何边界、复制和 OCR；浅/深模式检查 OCR 文字对比度并导出真实界面 PNG；执行逻辑测试、release 构建、应用签名和 DMG 校验。

## 应用图标扩展：A「轻盈取景」

用户明确选定应用图标方案 A：浅白色圆角底、蓝色两个开放取景转角和右上小方块。使用 Swift/AppKit 路径复现选定形状，保留可编辑源码与 1024 像素 PNG；系统 iconutil 编码包含 16–1024 像素和 Retina 变体的 ICNS。导出深浅背景及多尺寸预览，校验后打包为 1.2.1，保留已有菜单栏四角模板图标。
